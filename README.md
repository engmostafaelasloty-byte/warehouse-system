# Warehouse Management System (WMS) - Pro Edition 🏭

A modern, high-performance, and bilingual (Arabic & English) Warehouse Management System built with **Next.js 15**, **MongoDB**, and **Modern CSS**. This system is designed for small to medium-sized businesses to manage multiple warehouses, products, and inventory movements with ease.

## ✨ Key Features
- **🌍 Full Bilingual Support**: Toggle between Arabic (RTL) and English (LTR) seamlessly.
- **🏢 Multi-Warehouse Management**: Create and manage multiple warehouses with data isolation.
- **📦 Inventory Control**: Track product levels, categories, units, and minimum stock alerts.
- **📥 Incoming & Outgoing Management**: Professional tracking of inventory movements with automated stock updates.
- **📋 Transaction History**: Comprehensive logs of all movements with filtering and **CSV Export** capability.
- **📊 Interactive Dashboard**: Real-time stats and visual charts for quick decision-making.
- **⚡ High Performance**: Optimized for speed using Next.js internal font optimization and component memoization.
- **🔒 Data Security**: Implementation of MongoDB Transactions to ensure 100% data integrity.
- **📱 Responsive Design**: Premium dark-themed UI that works on all devices.

## 🚀 Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Database**: MongoDB (via Mongoose)
- **Styling**: Vanilla CSS (Custom Design System)
- **Icons/Fonts**: Google Fonts (Cairo & Inter) optimized via `next/font`

## 🛠️ Installation
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Configure your `.env.local` with your MongoDB URI.
4. Run `npm run dev` to start the development server.
